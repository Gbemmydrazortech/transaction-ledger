Transaction Ledger Dashboard

A responsive transaction management dashboard built with React, TypeScript, and CSS.

Features

- View transactions and their financial details.
- Add new income and expense transactions.
- Automatically update the displayed balance.
- Search transactions by description and other supported fields.
- Filter transactions by category.
- Persist transaction data across browser refreshes using localStorage.
- Display transaction amounts in Nigerian naira (₦).

Technologies

- React
- TypeScript
- CSS
- Vite
- Git and GitHub
- GitHub Pages

What I Learned

Through this project, I practised React state management, event handling, controlled form inputs, the useEffect hook, browser storage, TypeScript data modelling, searching, filtering, and deploying a frontend application.
